# VS Code Shortcuts

## Explorer

```text
Ctrl + Shift + E
```

Open de Explorer.

---

## Terminal

```text
Ctrl + `
```

Open of sluit de terminal.

---

## Open bestand

```text
Ctrl + P
```

Zoek een bestand.

---

## Command Palette

```text
Ctrl + Shift + P
```

Open alle VS Code-commando's.

---

## Wisselen tussen bestanden

```text
Ctrl + Tab
```

Ga naar het volgende geopende bestand.
