# VS Code Shortcuts

This document contains useful Visual Studio Code keyboard shortcuts for Windows.

---

## Explorer

```text id="yq6g2b"
Ctrl + Shift + E
```

Open or focus the Explorer.

---

## Integrated Terminal

```text id="43eqhx"
Ctrl + `
```

Open or close the integrated terminal.

---

## Quick Open

```text id="0ehtqb"
Ctrl + P
```

Quickly search for and open a file in the current workspace.

---

## Command Palette

```text id="ld2ccv"
Ctrl + Shift + P
```

Open the Command Palette.

The Command Palette provides access to VS Code commands and features.

---

## Switch Between Open Files

```text id="7f0vw4"
Ctrl + Tab
```

Switch between recently opened files.

---

## Save File

```text id="y0f54d"
Ctrl + S
```

Save the current file.

---

## Find

```text id="q93mc7"
Ctrl + F
```

Search within the current file.

---

## Find and Replace

```text id="l73p7f"
Ctrl + H
```

Search for text and replace it within the current file.

---

## Go to Line

```text id="p87oq5"
Ctrl + G
```

Jump directly to a specific line number.

---

## Toggle Comment

```text id="dy60a1"
Ctrl + /
```

Comment or uncomment the current line or selected lines.

This is particularly useful while testing and debugging code.

---

## Summary

```text id="a4x8dc"
Ctrl + Shift + E    Explorer
Ctrl + `            Integrated terminal
Ctrl + P            Quick Open
Ctrl + Shift + P    Command Palette
Ctrl + Tab          Switch open files
Ctrl + S            Save
Ctrl + F            Find
Ctrl + H            Find and replace
Ctrl + G            Go to line
Ctrl + /            Toggle comment
```
