# Branching

## Huidige werkwijze

Tijdens Python Crash Course werk ik rechtstreeks op:

```
main
```

Reden:

- kleine oefeningen;
- eenvoudig;
- weinig risico.

---

## Toekomstige workflow

Bij grotere projecten:

Nieuwe feature

↓

Nieuwe branch

↓

Code schrijven

↓

Testen

↓

Commit

↓

Push

↓

Merge naar main

Deze workflow wordt gebruikt zodra projecten groter worden.
