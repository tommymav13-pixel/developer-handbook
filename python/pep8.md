# PEP 8

## Doel

PEP 8 is de officiële stijlrichtlijn voor Python.

---

## Indentatie

- Gebruik 4 spaties.
- Geen tabs.

---

## Regellengte

- Maximaal 80 tekens.
- VS Code toont een vertical lijn op kolom 80

---

## Naamgeving

- variabelen: snake_case
- functies: snake_case
- klassen: PascalCase
- constanten: UPPER_CASE

---

## Lege regels

- Gebruik lege regels om code logisch te scheiden.

---

## Leesbaarheid

Code wordt vaker gelezen dan geschreven.

Schrijf code die ook over een jaar nog begrijpelijk is.

---

## Persoonlijk notities

- VS Code ingesteld op:
    - 4 spaties
    - Format on Save
    - Ruler op 80 tekens
