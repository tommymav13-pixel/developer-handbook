# Python Naming Conventions

## Bestandsnamen

Gebruik snake_case

Voorbeelden:

```text
hello_world.py
stock_analyzer.py
calculate_interest.py
```
Regels:

- kleine letters;
- woorden scheiden met een underscore (_);
- geen spaties;
- duidelijke, beschrijvende namen.

---

## Variabelen

Ook snake_case

Voorbeelden

```python
first_name
total_price
student_count
```

---

## Functies

Ook snake_case.

```python
def calculate_average():
    ...
```

---

## Klassen

PascalCase.

```python
class Student:
    ...
```

---

## Constanten

Hoofdletters.

```python
MAX_USERS = 100
PI = 3.14159
```

---

## Waarom?

- sluit aan bij PEP 8;
- consistente code;
- beter leesbaar;
- standaard binnen de Python-community
