# Project Ideas

## Development Philosophy

Start with a **Minimum Viable Product (MVP)**.

Focus on completing a working application before adding new features.

After each completed version, extend the project with **one additional feature**.

# Long-Term Goal

Develop projects that are:

- Personally useful.
- Increasingly challenging.
- Suitable for a professional portfolio.
- Reusable and expandable.

Every completed project should:

- Teach at least one new programming concept.
- Reinforce previously learned skills.
- Improve problem-solving ability.
- Become a stepping stone toward larger software projects.
